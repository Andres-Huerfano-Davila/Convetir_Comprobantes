# Generador de Gasto / Provisión SAP PCP0

Archivos principales:
- `app.py`: interfaz Streamlit
- `processor.py`: lógica de lectura y transformación
- `Instructivo.pdf`: manual de uso descargable
- `.streamlit/config.toml`: configuración de carga
- `requirements.txt`: dependencias

Tipos de entrada soportados:
- `.txt`
- `.xlsx`
- `.xls`
